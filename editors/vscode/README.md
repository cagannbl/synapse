# Synapse Language Support for Visual Studio Code

Official Visual Studio Code and OpenVSX extension for the **Synapse** AI-native programming language (`.syn`, `.ai`).

## Features

- **Syntax Highlighting**: Rich TextMate grammar for Synapse keywords, types, tensors, operators, and control flow.
- **Language Configuration**: Auto-closing brackets, quote pairing, indentation rules, and comment toggling (`#`).
- **Debugger Integration**: Launch and debug Synapse programs with the built-in Synapse DAP (Debug Adapter Protocol).
- **LSP Ready**: Compatible with Synapse Language Server Protocol.

## Getting Started

1. Open any file ending in `.syn`.
2. Syntax highlighting activates automatically.
3. Use `F5` or Run > Start Debugging to debug with the active file configuration.

## Requirements

- Synapse CLI (`synapse`) installed in your system `PATH`.
